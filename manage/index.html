Sound manager

Upload sounds, decide where they go, and manage what is on the site. Changes reach the website about a minute after saving.

How to make a token

On GitHub: your picture → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Resource owner: wildcareproject. Repository access: only wildcare. Permissions: Contents, Read and write. Copy the token and paste it above. The token works only for this repository; it stays in this browser and is sent only to GitHub.
